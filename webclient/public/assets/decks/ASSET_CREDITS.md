# Card artwork credits

The original deck uses the Belot application's original rank-and-suit renderer. The other choices use complete, locally bundled imported card artwork; no generated court faces or drawn regional suit shapes are used. Italian and German card faces keep their source proportions in the game, hand, and previews.

## French deck

Adrian Kennard's classic playing-card SVGs, packaged by [letele/playing-cards](https://github.com/letele/playing-cards). CC0 1.0. The deck license is included in `french/LICENSE`.

## Italian deck

Bresciane pattern card artwork by [ZZandro on Wikimedia Commons](https://commons.wikimedia.org/wiki/Category:Brescia_deck), licensed CC BY-SA 4.0. The SVG sources were rasterized to PNG for in-game use; card faces retain the source proportions. Attribution and license: [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Example source card: [07 Bastoni](https://commons.wikimedia.org/wiki/File:07-Bastoni.svg). The back uses the CC0 Modern deck back below.

## German deck

German-suited Skat card artwork by Gunter Gerhardt, with Wikimedia Commons files adapted and published by Mfrasca. Licensed CC BY-SA 3.0. The locally bundled SVGs remove the duplicated corner rank badges and inset outline while retaining the original pip and court artwork; the centered rank and suit label is rendered by the app. Attribution and license: [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/). Source set: [German Skat cards (SVG set by Mfrasca)](https://commons.wikimedia.org/wiki/Category:German_Skat_cards_(SVG_set_by_Mfrasca)); example source card: [Eichel 7](https://commons.wikimedia.org/wiki/File:Playing_card-german-eichel-07.svg). The back uses the CC0 Modern deck back below.

## Modern deck

Public-domain / CC0 vector card set by [AustinGabriel](https://github.com/AustinGabriel/Public-Domain-and-CC0-Playing-Cards). The license is included in `modern/LICENSE`.

## Heritage deck

Woodcut-style French-suited deck by [SONDLecT](https://github.com/SONDLecT/woodcut-cards), traced from public-domain historical decks and released under CC0 1.0. The license is included in `heritage/LICENSE`.

## Four-color deck

Four-color SVG deck by [Heratexx on OpenGameArt](https://opengameart.org/content/classic-4-color-poker-deck-svg), released under CC0 1.0. Hearts remain red, spades black, clubs use green, and diamonds use blue for faster suit distinction. The 32 Belot cards are bundled from the complete source set; the source does not include a card back, so the CC0 Modern back is reused. The CC0 license is included in `four-color/LICENSE`.

The local SVG / PNG image conversions are provided with their corresponding source licenses. Suit and rank IDs remain the game's original IDs; only presentation assets change.
